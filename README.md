# 💬 Chat App

A real-time multi-user chat application built from scratch using Node.js, Express, and Socket.io.

## Features
- Real-time messaging between multiple users
- Custom username support
- Clean dark-themed UI
- Message timestamps
- Works across multiple browser tabs and devices on the same network

## Tech Stack
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend:** Node.js, Express
- **Real-time:** Socket.io

## Getting Started

1. Clone the repo
   git clone https://github.com/yourusername/chat-app.git

2. Install dependencies
   npm install

3. Start the server
   node server.js

4. Open your browser
   http://localhost:3000
